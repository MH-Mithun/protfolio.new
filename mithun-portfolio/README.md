# Mithun Hossain — Portfolio

A responsive, premium glass-style student portfolio built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — page structure and content
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation, reveal animations, and dynamic year
- `assets/mithun-cv.pdf` — add your own CV PDF here

## Run locally

1. Open the folder in VS Code.
2. Add your CV at `assets/mithun-cv.pdf`.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Replace placeholder GitHub/LinkedIn URLs with your actual profiles.
5. Replace the sample projects with your real projects.

## Customization checklist

- Update the skill percentages in `index.html`.
- Replace sample project names and descriptions.
- Update project GitHub links.
- Add a real profile image if desired.
- Add your CV PDF inside the `assets` folder.
